\# 本地数字人视频完整操作流程

每次生成视频按以下顺序操作。需要手动输入讲稿。

\## 1. 启动 GPT-SoVITS API

打开一个新的 \`cmd.exe\` 窗口，执行：

\`\``cmd

cd /d D:\DigitalHuman\03_TTS\GPT-SoVITS-v5-20261005nvidia50x0\GPT-SoVITS-v5-20261006nvidia50x0

runtime\python.exe api.py -a 127.0.0.1 -p 9880 -g GPT_SoVITS\pretrained_models\s1v3.ckpt -s GPT_SoVITS\pretrained_models\gsv-v5-pretrained\s2Gv5turbo.pth

\`\``

等待 API 初始化完成，\*\*保持这个窗口打开\*\*。API 会加载模型并占用 GPU。

\## 2. 启动数字人网页服务

再打开一个新的 \`cmd.exe\` 窗口，执行：

\`\``cmd

D:\DigitalHuman\03_TTS\GPT-SoVITS-v5-20261005nvidia50x0\GPT-SoVITS-v5-20261006nvidia50x0\runtime\python.exe D:\DigitalHuman\06_Scripts\digital_human_generator.py

\`\``

看到本地服务启动提示后，保持这个窗口打开。

如果之后改过 \`digital_human_generator.py\`，要先在此窗口按 \`Ctrl+C\` 停止旧服务，再重新运行启动命令，才能加载修改后的程序。

\## 3. 打开页面并检查 API

在浏览器访问：

\[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

点击“检查 API 连接”。成功后再继续。

\## 4. 填写并生成

在页面中：

1. 输入中文讲稿。
2. 检查参考音频和参考文本。默认参考文本已填好；更换参考音频时，也要更新对应文本。
3. 确认头像、输出目录。
4. 一般保持语速 \`1.0\`、Wav2Lip box \`400 720 265 615\`。
5. 点击“生成数字人视频”，查看阶段和日志。

网页自动化程序会依次请求 GPT-SoVITS 合成 WAV、调用 Wav2Lip 生成口型视频，再运行 FFmpeg 补齐末帧并封装 MP4。当前程序会传入 \`--bottom_feather 24\`，用于减轻下巴下边缘分界线。

\## 5. 找到成品并关闭程序

成品路径会显示在页面上，任务文件保存在 \`D:\DigitalHuman\08_Output\` 下的独立任务目录中。每次任务使用新目录，不覆盖旧视频。

完成后可在网页服务窗口按 \`Ctrl+C\` 停止网页服务，再在 API 窗口按 \`Ctrl+C\` 停止 API。关闭服务不会删除已生成的任务文件。
