1.在github上下载一个m3u8player-main播放器项目文件

2.本地测试python -m http.server，然后浏览器输入http://localhost:8000/访问。

3.让AI进行二次开发的修改。

4.把文件夹上传到服务器/var/my目录下。

5.在AI指导下安装nginx，并配置nginx conf。

第一步：确认目录内容

执行：

ls -la /var/my/m3u8player-main

看看是否有：

index.html

js

image

README.md

第二步：创建 Nginx 配置

如果 nano 已安装：

nano /etc/nginx/sites-available/m3u8player

把原来内容全部删掉，写入：

server {

\    listen 80;

\    server_name 域名;

\    root /var/my/m3u8player-main;

\    index index.html;

\    location / {

\    try_files $uri $uri/ /index.html;

\    }

}

保存退出：

Ctrl + O

回车

Ctrl + X

第三步：启用配置

查看当前配置：

ls -l /etc/nginx/sites-enabled/

你应该会看到：

default -> /etc/nginx/sites-available/default

删除默认站点：

rm /etc/nginx/sites-enabled/default

创建软链接：

ln -s /etc/nginx/sites-available/m3u8player /etc/nginx/sites-enabled/

第四步：检查配置

执行：

nginx -t

如果出现：

syntax is ok

test is successful

说明配置没问题。

第五步：重载 Nginx

执行：

systemctl reload nginx

第六步：访问测试

浏览器访问：域名

有件很麻烦的事情，443端口被占用，解决办法是把SSL改为了灵活。具体细节可以问AI，它帮忙解决。
